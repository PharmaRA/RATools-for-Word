## 1. 目标与分工

用户通常同时进行撰写和排版，因此合并为一个撰写悬浮窗。定稿窗负责交付前检查与输出；图表引用窗作为跨阶段的专项工具，可以与撰写、审阅或定稿窗并用。

| 窗口 | 定位 | 典型使用方式 |
| --- | --- | --- |
| 现有快捷窗 | 跨阶段、高密度的通用入口 | 熟悉图标后，用一个小窗完成零散操作 |
| 撰写窗 | 正文结构、文字与日常排版 | 长时间撰写时常驻 |
| 现有审阅窗 | 修订、批注、审阅者与审阅处理 | 审阅时打开 |
| 定稿窗 | 检查、目录整理、清稿与交付 | 准备形成交付版本时打开 |
| 图表引用窗 | 图表、题注与引用的连续操作 | 图表密集编辑时与其他窗并用 |

首版主要复用现有功能。新增工作集中于窗口、菜单、按钮状态与定稿窗的轻量状态面板；既有工具的处理模式、作用范围、提示及保存规则继续沿用。

## 2. 撰写悬浮窗

### 2.1 布局

采用四列短按钮，接近现有快捷窗的操作密度。顶部显示当前文档名称，高频样式直接点击，低频样式与整篇处理通过菜单展开。

下表每行对应窗体的一行按钮；连续同名分区共用一个分区标题。

| 分区 | 第 1 列 | 第 2 列 | 第 3 列 | 第 4 列 |
| --- | --- | --- | --- | --- |
| 章节结构 | 标题 1 | 标题 2 | 标题 3 | 标题 4 |
| 章节结构 | 无编号 1 | 无编号 2 | 无编号 3 | 无编号 4 |
| 正文样式 | 正文 | 正文无缩进 | 正文无间距 | 更多样式 ▾ |
| 列表与文字 | 编号列表 | 项目符号 | 插入脚注 | 更多文字 ▾ |
| 段落格式 | 格式刷 | 清除格式 | 段落设置… | 段前分页 |
| 表格与页面 | 当前表适宽 | 选中文字标蓝 | 页面设置… | 更多排版 ▾ |

“标题 1”等采用短名称，提示气泡显示完整的 `标题1-F` 样式名。“段前分页”显示当前选区的对应状态；选区状态不一致时应表达为混合状态，避免显示成确定的开启或关闭。

### 2.2 菜单

| 菜单 | 内容 |
| --- | --- |
| 更多样式 | 编号标题 5–9、无编号标题 5–9、标题居中、标题左对齐、脚注样式、参考文献列表、样式窗格 |
| 更多文字 | 上标、下标、标准化科学术语下标、提取缩略语 |
| 更多排版：局部操作 | 插入分页符、插入分节符、页眉样式、页脚样式 |
| 更多排版：整篇处理 | 当前文档表格统一适宽、页眉页脚链接到前一节、批量设置页边距〔各节四边 2.54 cm〕 |

“更多排版”的局部操作与整篇处理之间用分隔线区分。页眉、页脚样式仍需在相应编辑区域执行。

### 2.3 作用范围

- 样式、文字和段落工具沿用当前选区或插入点的处理语义；科学术语标准化、缩略语提取等宏沿用各自现有范围，不能统一解释为只处理选区。
- “当前表适宽”只处理光标所在表格；“当前文档表格统一适宽”沿用现有主文档表格集合处理范围。
- “选中文字标蓝”与整篇链接、域标蓝区分，后者放在图表引用窗。
- 批量设置页边距继续提供现有模式选择；其数值为各节四边 2.54 cm。自定义边距通过“页面设置…”完成。
- 图表详细样式与题注引用集中在图表引用窗；撰写窗保留“当前表适宽”作为高频入口。

## 3. 定稿悬浮窗

### 3.1 顶部状态区

采用两列文字按钮。顶部增加轻量状态面板，属于本方案建议新增的界面能力：

```text
当前文档：《文件名》 · 有未保存修改
修订：—    批注：—    修订跟踪：—
状态读取时间：—                  [刷新]
```

显示当前文档的修订数、批注数和修订跟踪状态。未读取、读取失败与实际为零应明确区分。切换文档后重新读取；编辑后旧结果标记为“待刷新”，不把旧读数当作当前结论。

这块面板服务于当前文档快速判断；完整 clean 检测、高亮检测仍使用下面的既有工具，保留当前文档、多文件与文件夹模式。高亮检测不纳入 clean 判定。

### 3.2 按钮布局

| 分区 | 左侧按钮 | 右侧按钮 |
| --- | --- | --- |
| 交付前检查 | 检测 clean 版本… | 检测高亮内容… |
| 目录与引用 | 更新章节目录… | 更新图表目录… |
| 目录与引用 | 更新当前范围域 | 保护引用域格式 |
| 清稿与编号固定 | 接受修订并删除批注… | 标题编号转文本 |
| 保存与交付 | 保存当前文档 | 导出 PDF… |
| 保存与交付 | 重命名当前文件… | 打开所在文件夹 |

### 3.3 交互与边界

- “更新当前范围域”沿用 Word 当前选区或所在域的行为，不声明为全篇所有文字区域更新。
- 章节目录和图表目录按钮沿用现有目录定位与更新方式；光标不在相应目录时给出定位提示，不假设能够自动遍历所有目录。
- “保护引用域格式”沿用现有 `REF`、`PAGEREF` 的格式保留处理；有选区时处理选区，无选区时按当前正文域集合处理，不等同于冻结编号。
- “接受修订并删除批注”与“标题编号转文本”置于独立分区，和只读检查拉开距离。清稿沿用现有模式选择、关闭跟踪与保存规则。
- 标题编号转文本适合最终副本，仍按当前文档正文中的符合条件标题执行，不因选中文字而缩小范围，不自动另存或保存。
- “保存当前文档”独立提供；取消或失败不能显示保存成功。
- PDF 导出保留现有当前文档、多文件、文件夹模式，以及所见即所得、仅刷新页码、刷新整个目录三种选项；不把后两者描述为所有交叉引用的完整修复。
- 当前文档已有的未保存编辑可能进入 PDF，Word 原件不会因此自动保存；需要一致时先保存再导出。

推荐顺序：检查 → 整理目录和引用 → 按需清稿或固定编号 → 再次检查 → 保存并导出。各动作独立执行，留出检查结果的机会。

## 4. 图表引用悬浮窗

### 4.1 布局

采用两列文字按钮，按建立、排版、复制维护和目录组织。

| 分区 | 左侧按钮 | 右侧按钮 |
| --- | --- | --- |
| 建立题注与引用 | 生成题注与引用… | 插入题注… |
| 建立题注与引用 | 插入交叉引用… | 恢复题注标签 |
| 图表格式 | 表标题样式 | 图标题样式 |
| 图表格式 | 当前表适宽 | 更多图表工具 ▾ |
| 复制与维护 | 粘贴并重连引用 | 更新当前范围域 |
| 复制与维护 | 引用与链接标蓝 | 保护引用域格式 |
| 图表目录 | 插入图表目录… | 更新图表目录… |

### 4.2 更多图表工具

| 菜单组 | 内容 |
| --- | --- |
| 表格文字 | 表头左／中／右对齐、表格正文左／中／右对齐、无间距、表格注释 |
| 表格结构 | 插入表格、边框、重复标题行、拆分表格 |
| 图片 | 图片段落样式、嵌入型环绕 |

### 4.3 交互与边界

- “表标题样式”“图标题样式”只应用样式；自动编号通过题注功能建立。
- “生成题注与引用”仍要求光标位于正文、表格与现有域之外，取消文字选区；它不自动插入图片或表格。
- “粘贴并重连引用”本身包含粘贴，提示气泡明确写“复制后在目标位置点击，无需先粘贴”。无法唯一对应的目标沿用既有提示和人工确认方式。
- “恢复题注标签”用于恢复 Word 的题注类型入口，不承诺恢复已删除的引用目标或书签。
- “引用与链接标蓝”沿用当前文档的既有批量处理及排除规则，不能解释为只给选中的引用上色，也不能将改动数量当成引用检查报告。
- “更新当前范围域”“保护引用域格式”与定稿窗调用相同功能，范围和提示一致。

典型路径：

```text
新建图表：
生成题注与引用 → 放置题注和引用 → 应用图表样式 → 更新相关域

复用已有图表：
复制完整内容块 → 粘贴并重连引用 → 修改描述和数据 → 检查引用目标
```

## 5. 与现有快捷窗及审阅窗的关系

首版保留现有快捷窗六行四列、共 24 键的布局和操作，继续作为通用紧凑工具盘。新窗围绕完整任务分区，不要求用户迁移既有操作习惯。

允许少量高频功能重复出现。例如当前表适宽可出现在快捷、撰写和图表引用窗；高亮检测可出现在快捷、审阅和定稿窗。相同按钮复用同一现有动作，作用范围、模式选择与提示保持一致。

现有审阅窗保持其七项工具及分区，不因新增定稿窗而搬走 clean 检测、高亮检测或清稿入口。

### 5.1 统一入口

建议在功能区提供集中入口，同时保留现有快捷窗和审阅窗的直接入口：

```text
RATools → 工具窗 ▾
          快捷悬浮窗
          撰写悬浮窗
          审阅悬浮窗
          定稿悬浮窗
          图表引用悬浮窗
```

三个新窗顶部可提供同样的“工具窗 ▾”菜单，用于打开或隐藏其他窗。既有窗口不因打开新窗而自动关闭。

### 5.2 共同行为

- 各窗独立、非模态，可同时显示，分别记忆位置。
- 顶部显示目标文档，执行前重新取得当前活动文档和实际选区，不能作用于先前缓存的文档。
- 无文档时禁用需要文档的动作；菜单不应借此绕过禁用状态。
- 操作期间防止重复分发，成功、取消或异常后恢复状态；失效文档不能继续作为动作目标。
- 样式、排版执行后便于继续正文编辑；需要输入的题注、交叉引用等对话框保留交互焦点。
- 操作范围通过按钮名、分区和提示气泡表达；全篇、批量功能不暗示为仅处理选区。
- 工具窗之间共享动作，不为相同功能建立不同的业务处理副本。

## 6. 后续实施顺序与验收边界

实施顺序为撰写窗 → 定稿窗 → 图表引用窗 → 联合交付。每项单独测试、只读 review、更新 CHANGELOG 并提交；人工验证依赖单独记录，继续其他可执行工作。

| 阶段 | 主要交付 | 与交付直接相关的验证 |
| --- | --- | --- |
| 撰写窗 | 四列布局、样式与排版菜单、文档跟随及位置保存 | 样式和选区作用、当前表与整篇表格区分、菜单分发、无文档、焦点与异常恢复 |
| 定稿窗 | 两列布局、当前文档状态区、检查与导出入口 | 文档切换和旧状态失效、只读检查与修改动作区分、保存取消、PDF 选项和保存边界 |
| 图表引用窗 | 两列布局、图表菜单、题注引用与复制维护入口 | 生成位置限制、样式与自动题注区分、一次粘贴、引用目标及当前范围更新 |
| 联合交付 | 工具窗统一入口、文档与功能映射同步 | 与现有快捷及审阅窗共存、各窗位置与生命周期、Word COM 编译、成品源码匹配及限定只读 review |

实现时优先复用既有专项测试，只对新增行为和实际风险补充检查。自动化不能代替真实 Word 下的按钮可读性、菜单展开、焦点、提示气泡和 DPI 显示确认；结果应分别记录。

本轮不加入失效引用扫描、自动修复引用、全篇所有文字区域一键更新或一键完成全部定稿操作。这些能力不在上述窗口首版方案中。
