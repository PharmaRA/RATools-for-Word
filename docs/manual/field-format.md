# 链接标蓝与域格式保护

这两项功能分别解决引用的颜色和更新后的格式保留问题。需要正文中的引用以蓝色显示时，可以先设置颜色，再保护引用域的格式。

<a id="blue-links"></a>
## 超链接和域批量设置为蓝色

**入口：宏列表 → 超链接和域批量设置为蓝色，或快捷悬浮窗的对应按钮。**

1. 激活需要处理的文档；无需全选，该宏按当前文档范围运行。
2. 运行工具，等待完成提示。
3. 检查正文超链接、交叉引用以及题注和页码的颜色。
4. 需要保留结果时保存文档。

工具将超链接和符合条件的域结果设置为 RGB(0, 0, 255)。域检查会遍历正文及相连的页眉页脚等文字区域，并排除页码、总页数、题注序号、题注章节号、目录域及识别出的题注段落中的域。

**完成提示表示本次改动的对象数量，并不是一份完整的引用检查报告。** 自定义题注样式和特殊域代码可能影响识别。某些域代码包含“表”“图”“table”等题注相关文字时也可能被保留；如个别普通引用没有变蓝，可以选中它后使用“设为蓝色”，再检查更新后的效果。

如果题注本身含有另行插入的普通超链接，该超链接仍可能在超链接处理阶段变蓝。因此，不应把题注排除规则理解为题注段落内任何内容都绝不改变。

<a id="protect-format"></a>
## 保护域代码格式

**入口：RATools → 其他 → 保护域代码格式。**

1. 先把需要保护的交叉引用设为所需颜色和字体。
2. 如果只想处理部分引用，选中包含这些完整引用域的区域。
3. 点击“保护域代码格式”。若只有插入光标而没有选区，工具处理当前文档正文域集合；有选区时处理选区中的域。
4. 更新相关域，确认编号能变化、颜色和字体仍符合预期。
5. 保存文档。

工具给 `REF` 和 `PAGEREF` 引用域补上 `\* MERGEFORMAT` 开关，并更新新处理的域。已有该开关的域不重复添加。它不会把任意普通文字转换成引用，也不会冻结编号。

弹窗可能使用“全文”字样；这里不应理解为已经自动处理了所有页眉、页脚或文本框。需要保护其他区域的引用时，进入该区域，选中相关域后执行。

## 如何选择

| 需要 | 使用功能 |
| --- | --- |
| 只把当前选择的普通文字或一个引用设为蓝色 | 字体和段落 → 设为蓝色 |
| 统一当前文档中的链接及适用域的颜色 | 超链接和域批量设置为蓝色 |
| 更新引用后尽量保留当前结果格式 | 保护域代码格式 |
| 导出 PDF 时保持当前编号和引用结果 | PDF 导出的“所见即所得”选项，详见 [PDF 导出](pdf-export.md) |

“生成题注与引用”创建的新引用已经带有蓝色和格式保留设置；其他来源的旧引用仍应单独检查。
