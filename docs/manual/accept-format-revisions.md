# 接受格式修订

**入口：RATools → 审阅及修订 → 接受格式修订，或宏列表中的同名功能。**

适合文字内容还需要审阅，但字体、字号、段落格式等修改已经确认的情况。工具接受字符格式和段落格式类修订，保留插入、删除、替换、移动等内容类修订。

例如，把“样品”改成“试验样品”，同时修改了字体。执行后，字体修改可以成为正式格式，文字增加仍作为待审阅修订保留。

## 操作步骤

1. 激活目标文档，先完成或保存正在编辑的内容。建议先保存为本地 `.docx` 或 `.docm`。
2. 点击“接受格式修订”。它针对当前文档运行，不按当前文字选区限制范围；不同处理路径的区域覆盖见下文。
3. 对可走快速处理的文档，工具会先保存未保存的编辑，再询问是否生成备份。
4. 选择“是”保留原件备份，或按实际需要选择“否”。
5. 等待处理；快速路径可能关闭并重新打开当前文档。
6. 查看结果提示，再检查正文、页眉页脚及仍待审阅的内容修订。

## 备份和保存

快速处理的备份位于源文档旁，例如 `报告.docx.bak`。如果同名备份存在，会使用 `报告.docx.1.bak` 等新名称。选择不保留额外备份时，工具仍在处理期间保留用于恢复的副本。

快速处理会写回原文件并重新打开，不适合依靠 Word 的单次撤销恢复。需要还原时，保留当前结果，复制备份为正常 `.docx/.docm` 文件后再检查。

对于其他格式、不能映射到本地的云端文件，或快速路径不可用的情况，工具会使用 Word 兼容处理方式。兼容方式的修改保留在打开的文档中，检查后自行保存；不能假定每种路径都已经产生同样的 `.bak` 备份。

兼容处理按 Word 的主文档修订集合工作，不能视为已经检查和处理了页眉、页脚等所有文字区域。使用兼容模式后，应进入这些区域单独检查；结果提示中的数量也不能当成全区域统计。

## 结果如何理解

- “已接受 X 处格式类修订”：本次已处理的数量。它不表示文字内容修订已全部审阅。
- “仍有格式类修订无法接受”：可能与插入、删除等修订重叠，需要在 Word 中逐处检查。
- “未发现格式类修订”：可能只有内容类修订，或没有适用的格式变化。
- “快速处理失败，将使用兼容模式”：工具会尝试继续使用 Word 的处理方式，速度可能较慢。

单位策略限制外部处理程序时，也可能进入兼容模式。若提示“事务恢复未确认”或保留了原件副本路径，应停止重复操作，按提示检查原件和当前结果。

本功能不删除批注，不把所有修订接受为清洁稿，也不承诺处理所有类型的表格、节属性或其他特殊格式修订。需要完整清稿时，使用[清稿工具](clean-documents.md)。
