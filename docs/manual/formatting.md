# 字体与段落操作

入口：**RATools → 字体和段落**。这些入口把常用 Word 功能集中在一起。先选中要处理的文字；段落功能也可以直接作用于光标所在段落。

<a id="font-tools"></a>
## 文字格式

| 功能 | 操作步骤 | 结果与注意点 |
| --- | --- | --- |
| 清除格式 | 选中内容，点击清除格式 | 调用 Word 的清除格式命令；检查字体、段落及样式变化，误操作可立即撤销 |
| 格式刷 | 先选择格式正确的文字或段落，点击格式刷，再选取目标内容 | 将来源格式应用到目标；段落标记是否被包含会影响段落格式的复制 |
| 选择性粘贴 | 先复制内容，把光标移到目标位置，点击后选择粘贴格式 | 可按 Word 提供的选项保留格式、粘为文字或其他对象；保留引用时不要粘成纯文本 |
| 下标 | 选中需要降低位置的字符后点击 | 例如将 CO2 中的 2 设为下标；再次点击可切换该格式 |
| 上标 | 选中需要升高位置的字符后点击 | 例如把单位中的 2 设为上标；仅调整字形位置，不判断科学含义 |
| 字体颜色 | 选中文字，打开颜色菜单并选颜色 | 修改所选文字颜色 |
| 设为蓝色 | 选中文字后点击 | 设置为标准蓝色 RGB(0, 0, 255)；只有光标时会影响后续输入的文字格式 |
| 文本突出显示颜色 | 选中文字后选高亮颜色；需要清除时选择“无颜色” | 用于醒目标记待处理内容；与字体颜色、段落底纹不同 |
| 字体对话框 | 选中文字后打开，设置字体、字号或其他字体属性，确定 | 适合需要组合调整多项字体参数的情况 |
| 更改大小写 | 选中文字，打开菜单并选择大写、小写等方式 | 改变实际文字大小写；对大小写敏感的术语应检查结果 |

想统一全文引用的蓝色，请使用[超链接和域批量设置为蓝色](field-format.md#blue-links)。想批量处理指定科学术语的下标，请使用[标准化科学术语下标](scientific-terms.md)。

<a id="paragraph-tools"></a>
## 对齐、行距与段落设置

| 功能 | 操作步骤与结果 |
| --- | --- |
| 居中主按钮 | 光标放在目标段落或选中多个段落，点击主按钮直接居中 |
| 左对齐 | 打开对齐按钮下拉菜单，选择“左对齐”，让文字靠左排列 |
| 居中 | 在下拉菜单选择“居中”，与主按钮效果相同 |
| 右对齐 | 在下拉菜单选择“右对齐”，让文字靠右排列 |
| 两端对齐 | 在下拉菜单选择“两端对齐”，按 Word 规则调整行内间距 |
| 行距 | 打开行距菜单，选择需要的行距；更多参数可进段落设置 |
| 段落设置 | 打开 Word 段落对话框，设置缩进、段前段后间距、行距及换行分页属性，确定后检查 |

对齐主按钮固定执行“居中”，不是重复上次从菜单选的对齐方式。

<a id="page-break-before"></a>
## 段前分页

希望某个章节始终从新页开始时，可用“段前分页”：

1. 将光标放在该章节标题中，或选中需要处理的段落。
2. 点击 **段前分页**。
3. 该段落会按分页属性从新页开始。
4. 若选中段落全部已开启此属性，再点击会关闭；未开启或混合状态时，点击会统一开启。

它设置的是段落属性，不是在文中插入一个额外的分页符。若同时使用了手动分页符，可能出现多余空页，应在显示编辑标记后检查。普通格式操作不会自动保存文件，确认后按 `Ctrl+S`。
