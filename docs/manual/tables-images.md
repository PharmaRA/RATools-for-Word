# 表格与图片

先[加载模板](templates.md)。表格样式按钮主要给单元格中的段落指定格式，并不会自动生成一张包含全部数据的表格。

<a id="table-styles"></a>
## 表格文字样式

入口：**RATools → 表格**。选中要调整的单元格内容或段落，再点击对应按钮。

| 按钮 | 用途与检查点 |
| --- | --- |
| 表头左对齐-F | 表头文字靠左；适合描述型列名 |
| 表头居中-F | 表头文字居中；适合简短列名 |
| 表头右对齐-F | 表头文字靠右；检查与数据列的对齐关系 |
| 表格文本左对齐-F | 普通数据或说明文字靠左 |
| 表格文本居中-F | 普通单元格内容居中 |
| 表格文本右对齐-F | 普通单元格内容靠右；不等同于按小数点对齐 |
| 表格文本无间距-F | 使用模板中的紧凑单元格文字样式 |
| 表格注释-F | 表格说明、注释段落的统一格式 |
| 表格编号列表-F | 单元格内有顺序的多条内容 |
| 表格项目符号列表-F | 单元格内并列的多条内容 |
| 表标题-F | 表格上方的标题或题注段落；仅应用样式，不自动生成题注编号 |

例如，选中首行应用“表头居中-F”，选中说明列应用“表格文本左对齐-F”，再给表下说明应用“表格注释-F”。字体和间距取自模板；表格边框需单独设置。

<a id="table-tools"></a>
## 插入与调整表格

| 功能 | 操作方法 | 结果与限制 |
| --- | --- | --- |
| 插入表格 | 将光标放在插入点，打开 Word 表格菜单，选行数和列数 | 生成空表格，随后输入数据并应用文字样式 |
| 边框 | 选中单元格或整表，打开边框菜单选择边框方案 | 控制边框线，具体选项由 Word 提供 |
| 重复标题行 | 选中表格最上方的一行或连续多行，点击重复标题行 | 跨页时重复显示表头；在打印布局或预览中检查 |
| 拆分表格 | 光标放在希望成为第二张表首行的行内，点击拆分 | Word 将表格在此处拆开；原来的题注不会自动复制一份 |
| 根据窗口调整 | 光标放入目标表格，点击按钮 | 仅调整光标所在的表格，使其按可用页面宽度自动适应；光标不在表格中会提示 |

“根据窗口”是 Word 的表格自动调整方式。横向页面、页边距或嵌套布局会影响可用宽度，完成后检查列宽、换行和跨页情况。

<a id="autofit-all"></a>
## 一键表格自动调整

**入口：宏列表 → 一键表格自动调整。**

1. 激活需要处理的文档。
2. 运行该宏，无需逐个选中表格。
3. 插件遍历当前文档主文档表格集合，将表格设置为“根据窗口自动调整”，并提示处理数量。
4. 检查宽表、合并单元格和跨页表格，再保存。

这项宏作用于当前文档，不提供多文件选择窗口。不要把报告数量理解为已覆盖页眉、页脚或所有文本框中的表格。原来的固定列宽可能变化；需要保留精确列宽的表格，应先在副本上试用。没有表格时会提示并退出。

<a id="images"></a>
## 图片及图标题

入口：**RATools → 图片**。

| 按钮 | 操作方法与结果 |
| --- | --- |
| 图片-F | 光标放在承载图片的段落中，应用图片段落样式；不会自动插入、缩放或压缩图片 |
| 嵌入型环绕 | 选中图片，点击 Word 原生的嵌入型按钮，使图片像文字一样参与段落排版；适合希望随段落稳定移动的图片 |
| 图标题-F | 选中图片标题或题注段落，应用模板中的图标题格式；编号需通过题注功能生成 |

一个常见顺序是：用 Word 插入图片 → 设置为嵌入型 → 应用“图片-F” → 插入或[生成题注](caption-pairs.md) → 给题注应用“图标题-F”。检查图片清晰度与页面宽度后保存。
