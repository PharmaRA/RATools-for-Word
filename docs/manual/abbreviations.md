# 提取缩略语

**入口：宏列表 → 提取缩略语。** 用于从当前文档正文中整理英文缩略语候选，减少手工逐页查找。

## 操作步骤

1. 激活要提取的文档，无需选中文字。
2. 在宏列表中运行“提取缩略语”。
3. 有匹配结果时，工具新建一个 Word 文档，列出不重复的候选项，并按 A–Z 排序。
4. 逐项检查是否真的是需要解释的缩略语，删除无关候选，补充全称和说明。
5. 将新文档另行保存，或复制整理后的条目到正式文档的缩略语表。

若没有匹配项，会提示无发现，不生成有效候选列表。

## 识别规则与示例

工具按 Word 通配符匹配**以大写英文字母开头、后面至少再有一个大写字母或数字**的独立词。例如 `ICH`、`API`、`HPLC`、`A1` 都可能成为候选；重复出现的 `HPLC` 只列一次。

`eCTD`、`mRNA`、`Cmax` 等包含小写字母的写法不符合这条规则。单个大写字母也不会作为完整候选提取；带连字符等符号的术语可能被拆开匹配。

## 范围与结果含义

- 搜索范围是当前文档正文，包括正文中的表格文字；选择一段文字不会限制为只搜选区。
- 页眉、页脚、独立文本框等其他文字区域不属于这里的自动全文提取范围。
- 结果是按文字模式筛选的候选项，不判断术语含义，也不会生成英文全称、中文解释或参考出处。
- 原文档内容不被修改，生成的列表文档需要自行保存。

正式使用前，应人工移除全大写普通词、样品代码等不需要列入缩略语表的条目，并补充规则没有捕获到的术语。
