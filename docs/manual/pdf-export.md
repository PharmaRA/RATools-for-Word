# Word 批量转 PDF

**入口：宏列表 → Word批量转PDF。** 支持当前文档、多文件和包含子文件夹的文件夹模式。

## 三种转换选项

选择处理模式后，工具会再次询问转换选项。这两个输入框的 `1/2/3` 含义不同。

| 转换选项 | 具体行为 | 适合什么情况 |
| --- | --- | --- |
| `1` 所见即所得（默认） | 临时锁定域后导出，避免编号、目录或交叉引用在导出过程中被刷新；对原本打开的文档恢复各域原来的锁定状态 | 当前显示内容已经核对好，希望保留现有域结果 |
| `2` 仅刷新页码 | 更新章节目录和图表目录的页码，保留其条目文字 | 标题与题注没有变化，只调整了分页 |
| `3` 刷新整个目录 | 更新章节目录与图表目录的条目和页码 | 增删或改名了标题、题注，需要重新生成目录内容 |

选项 2、3 针对目录及图表目录，不等于执行全文所有交叉引用的完整修复。所见即所得也会保留原先的错误引用结果，所以应先检查再导出。Word 仍会重新分页，最终 PDF 需要检查。

## 导出当前文档

1. 保存文档至少一次，使它有明确的本地文件夹位置。
2. 运行宏，处理模式输入 `1`。
3. 选择转换选项，例如保持当前域结果时输入 `1`。
4. 等待完成提示，按提示路径打开 PDF。
5. 检查第一页、最后一页、横向页、宽表、页眉页脚和目录书签。

当前文档会保持打开。工具不主动保存 Word 原件；因此已有的未保存编辑可能出现在 PDF 中，而尚未写入 Word 文件。要让两者一致，请先自行保存再导出。

## 导出多个文件或整个文件夹

1. 运行宏，模式选择 `2` 或 `3`。
2. 选择转换选项。
3. 在选择窗口中指定文件，或指定包含 Word 文件的根文件夹。
4. 等待状态栏进度。工具可能短暂显示文档窗口，以保证 Word 正常渲染后导出。
5. 结束后查看成功和失败数量；选择“是”可生成详细处理报告。
6. 若要保留报告，请将新打开的报告文档另行保存。

## 输出位置与重名规则

PDF 与对应源文件位于同一文件夹，通常使用相同主文件名：

```text
研究报告.docx → 研究报告.pdf
```

已有同名 PDF 或同名目录时，当前源码会选择 `_1`、`_2` 等可用后缀，不覆盖原文件。例如再次导出得到 `研究报告_1.pdf`。以完成提示或报告中的实际路径为准。

导出请求按照 Word 标题创建 PDF 书签。只把文字加粗、放大而没有正确标题层级，不足以保证形成所需书签。

## 失败与限制

- 新文档未保存时，当前文档模式会提示先保存。
- 输出目录无写入权限、文件不可读、Word 无法完成排版时，可能导出失败；查看错误原因，处理后重新导出失败项。
- 云端路径若以网址形式呈现，可先另存本地工作副本，再从本地路径导出。
- 选项 2、3 对已打开文档的目录刷新可能留在内存中；工具不会替你决定是否保存这些变化。
- 如提示部分域锁定状态未恢复，应检查源文档，而不是仅因 PDF 存在就认为整个过程无异常。
- 此功能调用 Word 的 PDF 导出能力，不会自动完成申报文件的全部合规检查。
