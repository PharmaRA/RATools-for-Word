# 标题、正文与列表样式

**使用前先[加载模板](templates.md)。** 样式让同类内容保持统一，并保留段落的语义层级，便于生成目录和 PDF 书签。

## 通用操作

1. 把光标放在目标段落内，或者选中多个需要同样排版的段落。
2. 点击对应样式按钮；纯图标按钮可悬停查看名称。
3. 查看样式窗格、导航窗格和实际排版，确认应用结果。
4. 按 `Ctrl+S` 保存。应用错误时可立即使用 Word 撤销；批量选中正文时不要把不应改动的标题、题注也选进去。

字体、字号、缩进与间距取自所加载的模板，按钮不会保证一个与模板无关的固定数值。手动设置的直接格式也可能影响最终外观。

<a id="numbered-headings"></a>
## 编号标题 1–9

入口：**RATools → 编号标题**。下表每个名称对应一个独立按钮。

| 按钮 | 用途与层级 |
| --- | --- |
| 标题1-F | 文档的一级章节，例如“质量研究” |
| 标题2-F | 一级章节下的二级内容，例如“分析方法” |
| 标题3-F | 二级内容下的三级内容，例如“方法验证” |
| 标题4-F | 四级标题，用于进一步细分 |
| 标题5-F | 五级标题，仅在文档结构需要时使用 |
| 标题6-F | 六级标题 |
| 标题7-F | 七级标题 |
| 标题8-F | 八级标题 |
| 标题9-F | 九级标题 |

编号形式由模板中的列表定义决定。不要为得到某个外观而随意跳级，也不要同时手动输入一套编号。如果正文显示两个编号，检查是否既保留了手输文字编号，又应用了自动编号样式。

需要把编号永久变成普通文字时，另见[标题自动编号转文本](heading-numbers.md)。该操作会失去随标题增删自动重排编号的能力。

<a id="unnumbered-headings"></a>
## 无编号标题 1–9

入口：**RATools → 无编号标题**。使用方法与编号标题相同，适合需要标题层级但不需要显示序号的内容。

| 按钮 | 用途 |
| --- | --- |
| 无编号标题1-F | 不显示编号的一级标题 |
| 无编号标题2-F | 不显示编号的二级标题 |
| 无编号标题3-F | 不显示编号的三级标题 |
| 无编号标题4-F | 不显示编号的四级标题 |
| 无编号标题5-F | 不显示编号的五级标题 |
| 无编号标题6-F | 不显示编号的六级标题 |
| 无编号标题7-F | 不显示编号的七级标题 |
| 无编号标题8-F | 不显示编号的八级标题 |
| 无编号标题9-F | 不显示编号的九级标题 |

这些标题是否进入目录，取决于模板的大纲级别与目录设置。生成目录后应检查包含的层级，不能仅根据是否显示编号判断。

<a id="basic-styles"></a>
## 基础样式

入口：**RATools → 基础样式**。

| 按钮 | 什么时候用 | 如何操作与确认 |
| --- | --- | --- |
| 标题居中-F | 需要居中的文档标题 | 光标放在标题段落，点击后检查对齐；章节标题仍按所需层级选择 |
| 标题左对齐-F | 需要左对齐的文档标题 | 应用到标题段落；字体与间距取自模板 |
| 目录标题-F | “目录”等目录上方的标题 | 选中目录标题段应用；该按钮本身不生成目录内容 |
| 正文-F | 普通正文段落 | 应用正文格式；英文模板映射为带缩进的正文样式 |
| 正文无缩进-F | 不需要首行缩进的正文 | 选择对应段落后应用，检查左边界与首行 |
| 正文无间距-F | 需要紧凑排列的正文 | 应用后检查段前、段后间距；具体参数以模板为准 |
| 脚注-F | 已经插入的脚注文字 | 先进入脚注区域，再应用样式；插入脚注请用引用组的脚注按钮 |
| 样式窗格 | 查看、选择或修改当前文档样式 | 点击显示或隐藏 Word 样式窗格；可查找实际应用的中英文样式名 |

样式窗格里的修改通常针对当前文档。需要以后都使用新定义，请按[自定义模板](customization.md#custom-templates)修改 `.dotx`。

<a id="lists"></a>
## 列表样式与列表操作

入口：**RATools → 列表**。

| 按钮 | 操作方法与结果 |
| --- | --- |
| 编号列表-F | 选中一组正文列表段落后应用，得到模板定义的有序列表 |
| 项目符号列表-F | 选中并列条目后应用，得到模板定义的符号列表 |
| 参考文献列表-F | 选中文献条目后应用，统一文献列表排版；不会自动补全文献信息或核对引文 |
| 重新开始编号 | 光标放在要重新起算的列表项，点击 Word 原生按钮；检查它是否成为新列表的起点 |
| 增加缩进 | 选中列表段落后点击，调整缩进或列表层级，具体取决于当前列表定义 |
| 减少缩进 | 将列表段落向外一级调整；检查序号和缩进是否符合预期 |

正文列表与章节标题是两种用途。需要章节出现在导航和目录中时，应使用标题样式。

表格专用样式见[表格与图片](tables-images.md)，页眉与页脚样式见[页面与页边距](page-layout.md)。
