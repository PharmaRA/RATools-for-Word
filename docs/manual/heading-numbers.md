# 标题自动编号转文本

**入口：宏列表 → 标题自动编号转文本。**

适合在最终副本中固定章节编号，避免后续复制或使用环境变化导致自动编号重新排列。仍在频繁增删章节的工作稿，通常应继续保留自动编号。

## 操作步骤

1. 先检查标题编号是否正确，并保留一份仍带自动编号的工作稿。
2. 激活要转换的文档，打开宏列表并运行本功能。
3. 工具检查当前文档正文段落，处理大纲级别为 1–9 且带列表编号的标题。
4. 查看完成提示中的标题数量，检查章节号与标题文字。
5. 保存转换后的版本。

例如，原来由 Word 生成的“2.3 分析方法”，转换后编号部分成为固定文字。以后在前面插入新章节时，这一编号不会再自动变成“2.4”。

## 处理范围与限制

- 宏按当前文档运行，选择部分文字不会把它限制为只处理选区。
- 无编号标题、没有自动编号的段落不属于转换对象。
- 根据大纲级别识别标题，不要求标题必须使用 RATools 样式。
- 转换后若再应用带编号的标题样式，可能出现“自动编号 + 原静态编号”双重显示，需要人工整理。
- 工具不自动另存为、不自动保存。转换后应检查目录、交叉引用和导航效果；需要恢复自动编号时，优先立即撤销或返回原工作稿。
