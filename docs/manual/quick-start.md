# 第一次使用

这次练习会得到一份带有标题、正文、题注和交叉引用的简单文档。请先完成[安装](installation.md)。

## 1. 新建并保存练习文档

在 Word 中新建普通文档，保存为 `RATools练习.docx`。输入两段：

```text
稳定性研究
本节介绍样品在各时间点的检测结果。
```

保存后再加载样式，便于模板导入和后续输出文件定位。

## 2. 加载需要的模板

进入 **RATools → 模板**，点击“加载”下方的箭头，选择 **加载中文模板 (CN)**。英文文档选择 **加载英文模板 (EN)**。

看到导入完成提示后继续。如果没有找到模板，按提示手动选择 `.dotx` 文件。加载动作把样式定义导入当前文档，不会替你把所有段落分配到正确的标题或正文样式。

## 3. 给段落指定用途

1. 将光标放到“稳定性研究”这一段，点击 **编号标题 → 标题1-F**。
2. 将光标放到第二段，点击 **基础样式 → 正文-F**。
3. 在 Word 导航窗格中检查标题层级，查看字体、间距和编号是否符合所用模板。

如果只有光标，段落样式作用于当前段落；选中多个段落时，可以一次应用同一个样式。需要更深层级时使用标题2-F、标题3-F等，而不是只手动调小字号。

## 4. 生成一组题注与引用

1. 在正文末尾另起一段，将光标放在空段中，不要选中文字，也不要放在表格内。
2. 点击 **引用 → 生成题注与引用**。
3. 选择标签“表”，题注文字填写“稳定性试验结果”，点击“生成”。
4. 你会得到相邻两段，类似：

```text
表 1
表 1 稳定性试验结果
```

第一段是可更新的交叉引用，第二段是题注。数字由文档的题注序列决定，未必从 1 开始。

要放入正式文稿，可剪切整段引用到说明文字附近，把整段题注移到表格上方。移动后选中相关内容，点击 **更新域**；如果引用在题注前面，可能需要再更新一次。详细操作见[生成题注与引用](caption-pairs.md)。

## 5. 找到更多工具

点击 **宏列表**，在搜索框输入“高亮”或“PDF”，选择功能后阅读窗口下方的说明，再点击“运行”或双击功能名称。

批量功能通常会先询问处理模式。第一次练习选择 **1：仅当前文档**；不同功能如何保存，见[批量模式与保存规则](batch-basics.md)。

## 6. 检查并保存

确认标题层级、正文样式、题注编号和引用目标，然后按 `Ctrl+S` 保存。想继续练习整套流程，可阅读[常见工作流程](workflows.md)。
