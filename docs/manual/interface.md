# 宏管理器、悬浮窗与关于

<a id="macro-manager"></a>
## 宏管理器

**入口：RATools → 宏列表中的宏列表按钮。** 打开的窗口标题为“宏管理器”。

1. 在列表中单击功能名称，阅读下方的详细说明。
2. 点击运行按钮，或直接双击该功能。
3. 若功能较多，在搜索框中输入关键词，例如“PDF”“页边距”“修订”。搜索同时匹配中文名称、宏过程名和功能说明，不区分英文大小写。
4. 清空搜索框可以重新显示全部功能；刷新按钮重新载入列表并清空搜索。
5. 窗口可调整大小，也允许回到文档继续编辑。运行前先确认当前活动文档和选区。

宏管理器只是启动入口。是否出现模式选择、是否保存原文件、是否生成报告，都由具体工具决定。

## 工具窗统一入口

**入口：RATools → 工具窗菜单。** 可选择快捷、撰写、审阅、定稿或图表引用悬浮窗。三个新窗顶部也有相同的“工具窗”菜单；再次选择已显示的窗口会隐藏它，各窗可以同时使用并分别记住位置。

| 工具窗 | 适合的工作 |
| --- | --- |
| [快捷悬浮窗](#quick-toolbar) | 用 24 个紧凑图标完成零散操作 |
| [撰写悬浮窗](#writing-toolbar) | 正文结构、文字与日常排版 |
| 审阅悬浮窗 | 修订、批注、审阅者筛选与审阅处理 |
| [定稿悬浮窗](#final-toolbar) | 交付前检查、清稿、保存与输出 |
| [图表引用悬浮窗](#references-toolbar) | 图表、题注与引用的连续编辑 |

先在文档中选择目标，再点击相应按钮。切换文档后，新窗显示当前目标文档；没有打开文档时仍可切换工具窗，需要文档的操作会禁用。运行期间按钮和菜单暂时禁用，结束或取消后恢复。快捷窗及审阅窗也保留原有直接入口。

<a id="writing-toolbar"></a>
## 撰写悬浮窗

**入口：RATools → 工具窗 → 撰写悬浮窗。** 四列布局合并撰写与排版，样式按钮的提示显示完整名称。

| 分区 | 从左到右的入口 |
| --- | --- |
| 章节结构 | 标题 1、标题 2、标题 3、标题 4 |
| 章节结构 | 无编号 1、无编号 2、无编号 3、无编号 4 |
| 正文样式 | 正文、正文无缩进、正文无间距、更多样式 |
| 列表与文字 | 编号列表、项目符号、插入脚注、更多文字 |
| 段落格式 | 格式刷、清除格式、段落设置、段前分页 |
| 表格与页面 | 当前表适宽、选中文字标蓝、页面设置、更多排版 |

“更多样式”提供编号标题 5–9、无编号标题 5–9、标题居中、标题左对齐、脚注样式、参考文献列表和样式窗格。“更多文字”提供上标、下标、科学术语下标标准化和缩略语提取。

“更多排版”把插入分页符、插入分节符、页眉样式和页脚样式，与当前文档表格统一适宽、页眉页脚链接到前一节、批量设置页边距分组显示。批量页边距仍保留模式选择，各节四边为 2.54 cm；自定义边距使用“页面设置”。

样式、文字和段落按钮跟随实际选区或插入点。“段前分页”在选区状态不一致时显示“混合”。“当前表适宽”只调整光标所在表格，“选中文字标蓝”只处理选区；整篇表格、科学术语和缩略语工具沿用各自范围。页眉或页脚样式应在相应编辑区域执行。详情见[样式](styles.md)、[字体与段落](formatting.md)、[页面与页眉页脚](page-layout.md)。

<a id="final-toolbar"></a>
## 定稿悬浮窗

**入口：RATools → 工具窗 → 定稿悬浮窗。** 顶部显示当前文档是否保存，以及修订数、批注数、跟踪状态和读取时间。未读取、读取失败与实际为零分别显示；切换文档或重新打开窗口会重读，编辑后旧读数标为“待刷新”，可点击“刷新”重读。

| 分区 | 左侧入口 | 右侧入口 |
| --- | --- | --- |
| 交付前检查 | 检测 clean 版本 | 检测高亮内容 |
| 目录与引用 | 更新章节目录 | 更新图表目录 |
| 目录与引用 | 更新当前范围域 | 保护引用域格式 |
| 清稿与编号固定 | 接受修订并删除批注 | 标题编号转文本 |
| 保存与交付 | 保存当前文档 | 导出 PDF |
| 保存与交付 | 重命名当前文件 | 打开所在文件夹 |

状态区提供当前文档的快速判断，完整 clean 与高亮检测保留原处理模式；高亮不纳入 clean 判定。目录更新沿用原定位提示，“更新当前范围域”处理当前选区或所在域。引用格式保护处理 REF/PAGEREF：有选区时处理选区，无选区时处理当前正文域集合。

清稿继续沿用原模式、关闭跟踪与保存规则。标题编号转文本处理当前正文中的符合条件标题，适合最终副本，不自动另存或保存。保存取消或失败后，顶部保留实际未保存状态。PDF 导出保留原处理模式和目录刷新选项；未保存编辑可能进入 PDF，Word 原件不会因此自动保存，需要一致时先保存再导出。详情见[clean 检测](review.md#clean-detection)、[清稿](clean-documents.md)、[编号固定](heading-numbers.md)、[PDF 导出](pdf-export.md)。

<a id="references-toolbar"></a>
## 图表引用悬浮窗

**入口：RATools → 工具窗 → 图表引用悬浮窗。** 两列入口适合与撰写、审阅或定稿窗并用。

| 分区 | 左侧入口 | 右侧入口 |
| --- | --- | --- |
| 建立题注与引用 | 生成题注与引用 | 插入题注 |
| 建立题注与引用 | 插入交叉引用 | 恢复题注标签 |
| 图表格式 | 表标题样式 | 图标题样式 |
| 图表格式 | 当前表适宽 | 更多图表工具 |
| 复制与维护 | 粘贴并重连引用 | 更新当前范围域 |
| 复制与维护 | 引用与链接标蓝 | 保护引用域格式 |
| 图表目录 | 插入图表目录 | 更新图表目录 |

“更多图表工具”按表格文字、表格结构和图片分组，提供表头左/中/右对齐、表格正文左/中/右对齐、无间距、表格注释、插入表格、边框、重复标题行、拆分表格、图片段落样式和嵌入型环绕。

“生成题注与引用”要求光标位于正文中、表格和现有域之外，并取消文字选区；图片和表格需自行插入。表标题、图标题按钮只应用样式，自动编号通过题注功能建立。“恢复题注标签”恢复 Word 的题注类型入口，引用目标及书签的恢复需另行处理。

复制完整内容块后，在目标位置直接点击“粘贴并重连引用”，无需先粘贴；无法唯一对应的目标沿用原提示和人工确认。引用与链接标蓝沿用当前文档的批量范围及排除规则，结果表示改动数量。当前范围域更新和引用格式保护与定稿窗一致。详情见[题注、交叉引用与目录](references.md)、[生成题注与引用](caption-pairs.md)、[粘贴重连](paste-relink.md)、[表格与图片](tables-images.md)、[域格式保护](field-format.md)。

## 审阅悬浮窗

**入口：RATools → 审阅及修订 → 审阅悬浮窗。** 七项审阅工具按日常审阅、格式处理、定稿前检查、清稿处理分区，可与快捷悬浮窗同时使用。详情见[审阅悬浮窗](review.md#review-toolbar)。

## 快捷悬浮窗

**入口：RATools → 宏列表 → 快捷悬浮窗。** 再点击可以隐藏；窗口自身的关闭按钮也可以关闭窗口。

悬浮窗提供六行四列共 24 个按钮。它不会阻塞文档编辑，可拖动到顺手的位置，并保存上次位置。先在文档中选好目标，再点击悬浮窗；鼠标停在图标上可以查看名称和说明。

| 行 | 从左到右的四个功能 | 使用说明 |
| --- | --- | --- |
| 第 1 行 | 编号标题 1、2、3、4 | [编号标题](styles.md#numbered-headings) |
| 第 2 行 | 无编号标题 1、2、3、4 | [无编号标题](styles.md#unnumbered-headings) |
| 第 3 行 | 正文、表标题、图标题、段前分页 | [基础样式](styles.md#basic-styles)、[表格图片](tables-images.md)、[段前分页](formatting.md#page-break-before) |
| 第 4 行 | 格式刷、段落设置、清除格式、设为蓝色 | [字体与段落](formatting.md) |
| 第 5 行 | 根据窗口调整表格、插入题注、插入交叉引用、更新域 | [当前表格调整](tables-images.md#table-tools)、[题注与引用](references.md) |
| 第 6 行 | 粘贴并重连引用、超链接和域批量设置为蓝色、接受修订并删除批注、检测高亮内容 | [重连](paste-relink.md)、[标蓝](field-format.md#blue-links)、[清稿](clean-documents.md)、[高亮](highlights.md) |

标题 5–9 和无编号标题 5–9 在功能区中使用。悬浮窗中的批量宏仍会弹出相应模式选择；点击悬浮窗的清稿按钮不意味着只处理选中的文字。

切换 Word 文档后，按钮作用于当前活动文档。文档都已关闭时，应先打开文档再使用编辑类按钮。

## 关于与检查更新

**入口：RATools → 关于。**

| 操作 | 结果 |
| --- | --- |
| 查看当前版本 | 显示已加载插件的版本标识；反馈问题时可记录此版本 |
| GitHub | 用浏览器打开项目 GitHub 仓库 |
| Gitee | 用浏览器打开项目 Gitee 仓库 |
| 检查更新 | 查询发布版本；发现新版本后，可按弹窗提示打开 GitHub 或 Gitee 的发布详情页 |
| 关闭 | 退出关于窗口 |

检查更新需要联网。网络失败不代表当前版本已经最新，可手动查看[发布页面](https://github.com/PharmaRA/RATools-for-Word/releases)。插件不会因此自动替换当前文件，后续按照[更新步骤](installation.md)安装。
