# 页面、页眉页脚与页边距

<a id="layout-tools"></a>
## 布局组的常用按钮

入口：**RATools → 布局**。

| 功能 | 操作步骤 | 结果与注意点 |
| --- | --- | --- |
| 页眉-F | 双击页眉进入编辑，把光标放到对应段落后点击 | 应用模板里的页眉样式；不自动填入页眉文字 |
| 页脚-F | 双击页脚进入编辑，再点击样式按钮 | 应用页脚样式；不自动插入页码 |
| 插入分页符 | 光标放在下一页内容之前，点击分页符 | 在当前位置插入手动分页符；需要标题始终另起页时也可使用[段前分页](formatting.md#page-break-before) |
| 插入分节符 | 光标放在节的分界位置，点击 Word 原生分节入口完成插入；需要明确选择下一页、连续等类型时，也可在 Word 的“布局 → 分隔符”中操作 | 分节允许不同部分使用不同页面和页眉页脚设置；具体入口界面以 Word 版本为准，插入后检查空白页与节的位置 |
| 页面设置 | 打开 Word 页面设置窗口，调整页边距、纸张、方向和布局，确认“应用于”的范围后确定 | 可针对整篇或某些节设置；不要忽略作用范围 |
| 插入对齐制表位 | 编辑页眉或页脚时，把光标放在需要对齐的位置，打开窗口选择左、中、右对齐等选项 | 在同一行组织页眉页脚内容；具体效果由 Word 和当前页边距决定 |

要查看分页符、分节符，可在 Word 中打开显示编辑标记。分节符影响文档结构，不宜只为了把一段文字推到下一页而随意插入。

<a id="link-sections"></a>
## 页眉和页脚设置为“链接到前一节”

**入口：宏列表 → 页眉和页脚设置为“链接到前一节”。**

适合多个节应使用一致页眉页脚，而导入或拼接文档后出现断开的情况。

1. 先确认后续各节确实应该沿用前一节的页眉页脚内容。
2. 运行该宏。
3. 工具从第二节开始，为各节的主页、首页、偶数页页眉及页脚设置“链接到前一节”。
4. 检查各节首页、奇偶页和页码区域，再保存。

只有一节时会提示无需链接。该宏修改当前文档，不提供文件夹模式，不会自动保存。

链接后，各节原本独立的页眉页脚可能改为沿用前一节。若封面、附录或某些章节需要独立内容，应使用 Word 原生设置逐节处理。此功能也不会自动统一“首页不同”“奇偶页不同”或页码起始值等其他选项。

<a id="batch-margins"></a>
## 批量设置页边距

**入口：宏列表 → 批量设置页边距。** 运行窗口的标题可能显示“一键设置页边距”。

它把文档**所有节**的上、下、左、右页边距都设为 **2.54 厘米（72 磅）**，包括横向和纵向页面所在的节。此工具没有自定义数值输入；需要其他数值时使用上面的页面设置。

1. 打开宏列表，搜索“页边距”并运行。
2. 输入模式：`1` 当前文档、`2` 多文件、`3` 文件夹。
3. 多文件模式选择 `.doc/.docx/.docm`；文件夹模式会包含子文件夹。
4. 等待结果提示，检查所有节的排版，尤其是宽表、图片和分页。

### 保存方式

| 文档状态 | 处理后的行为 |
| --- | --- |
| 当前文档模式 | 直接修改当前文档并重新分页；检查后自行保存 |
| 批量模式中原本已打开的文档 | 保留打开，修改在内存中，需自行保存 |
| 批量模式中由工具打开的文档 | 保存到原文件并关闭；不另建一份输出文档 |

受保护文档会跳过或提示失败。保存取消或失败时，相关文档可能保持打开供你检查；不要把“已设置边距”当成“已经成功保存”。此功能只改四边页边距，不设置纸张、方向、装订线或页眉页脚距离。
