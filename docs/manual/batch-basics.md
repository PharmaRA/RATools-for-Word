# 批量模式与保存规则

批量工具可以减少重复操作，但各工具的输入与保存方式不同。先确认本页的模式含义，再阅读相应功能页。

<a id="modes"></a>
## 通用的三种模式

Word 转 PDF、设置页边距、接受修订并删除批注、检测高亮使用同一类模式输入框：

| 输入 | 模式 | 处理范围 |
| --- | --- | --- |
| `1` | 仅当前文档 | 当前活动的 Word 文档；有多个窗口时先激活目标文档 |
| `2` | 多文件模式 | 在文件选择窗口中选择一个或多个 `.doc`、`.docx`、`.docm`，可按住 Ctrl 或 Shift 多选 |
| `3` | 文件夹模式 | 所选文件夹及其子文件夹中的上述 Word 文档，跳过 `~$` 开头的临时文件 |

输入框默认通常为 `1`。取消或留空会退出本次选择。文件夹模式没有逐个文件的确认步骤；如果只想处理少数文件，使用多文件模式。

“批量修改文件名”使用另一套 **是＝文件夹、否＝多文件**选择，而且处理所有类型文件，详见[重命名说明](batch-rename.md)。“一键表格自动调整”则仅处理当前文档内的多张表格。

<a id="saving"></a>
## 哪些功能会写回原文件

| 功能 | 当前文档模式 | 批量选择文件后的行为 |
| --- | --- | --- |
| Word 批量转 PDF | 新建 PDF，不主动保存 Word 原文档；刷新目录选项可能改变当前内存内容 | 新开文档按只读方式导出后关闭；原本打开的文档保持打开 |
| 批量设置页边距 | 修改当前文档，需手动保存 | 工具打开的文档保存原件并关闭；原本打开的文档需手动保存 |
| 批量接受修订并删除批注 | 修改当前文档，需手动保存 | 写回所选原文件；原本打开的文档也会尝试保存，可能连同其他未保存编辑一起保存 |
| 批量检测高亮内容 | 只检测并可跳转 | 只检测源文档，另建一份报告，由你保存报告 |
| 批量修改文件名 | 无此模式 | 直接重命名磁盘文件；重命名失败时尝试创建新名称副本 |

这些操作没有统一的“一键撤回整个文件夹”功能。工具已经保存或关闭文档、改动磁盘文件名后，不能依靠当前 Word 窗口的撤销来恢复所有文件。需要保留原版时，先把明确要处理的文件复制到工作副本目录。

## 怎样判断是否成功

1. 看完成提示中的成功和失败数量，不只看窗口是否已经关闭。
2. 对 PDF 查看实际输出路径和详细报告；对高亮检查报告中的“无法打开”“检测失败”等状态。
3. 若保存失败导致文档仍保持打开，先确认内容并手动保存到可写位置。
4. 抽查处理结果，例如页边距、修订是否残留、PDF 页数和目录跳转。

文件被占用、只读、受保护、没有目录权限，或云端文件尚未同步到本地，都可能影响处理。文件夹扫描不能代替一份已核对的输入清单；无法访问的目录中的文件可能没有进入处理列表。
