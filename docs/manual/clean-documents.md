# 批量接受修订并删除批注

**入口：宏列表 → 批量接受修订并删除批注，或快捷悬浮窗对应按钮。**

适合内容意见已经确认、需要从审阅稿制作清洁稿的阶段。它会接受修订、删除批注并关闭继续记录修订的开关。

## 处理前确认

保留需要追溯的审阅稿副本。工具没有让你逐条选择接受或拒绝的步骤，也没有自动生成 `_clean` 文件名的规则。批量模式会把结果写回所选原文件。

如果仅想隐藏某位作者，使用[审阅者筛选](review.md#reviewer-filter)；如果文字修改仍待审阅，只想接受格式变化，使用[接受格式修订](accept-format-revisions.md)。

## 操作步骤

1. 在宏列表搜索“修订”并选择本功能。
2. 输入模式：`1` 当前文档、`2` 多文件、`3` 文件夹。
3. 如选多文件或文件夹，指定目标；文件夹模式包含子文件夹中的 Word 文档。
4. 等待完成提示，记录失败数量。
5. 检查 Word 的审阅窗格，确认应清除的修订和批注已消失，并确认修订开关关闭。
6. 再运行[高亮检测](highlights.md)，检查是否还有需人工处理的标记。

## 处理范围与附带影响

工具尝试清理正文、脚注、尾注、页眉页脚等区域以及相关文本框/图形中的修订，反复处理带回复的批注。它还会解除所处理区域中的域锁定状态。

因此，完成后某些原先锁定的目录、编号或引用可能在今后更新时发生变化，应在导出前核对。高亮、字体颜色、隐藏文字和文档元数据不属于此工具的完整清理目标。

受密码保护的文档不能假定会成功处理。复杂修订、嵌套批注或 Word 自身限制也可能留下需人工检查的内容；不能仅凭完成弹窗认定文档已满足全部交付要求。

## 保存方式

- **当前文档模式**：修改打开的文档，不主动保存；检查后自行保存。
- **多文件、文件夹模式**：尝试保存到每个原文件；工具自己打开的文档保存后关闭。
- **批量列表里原本已打开的文档**：保持打开，但也会尝试保存，可能同时保存你此前未保存的其他编辑。
- **保存失败或被取消**：相关文档可能保持打开，失败计数中会反映；检查后手动保存到可写位置。

批量结果无法通过当前文档的一次 `Ctrl+Z` 整体还原。需要恢复多个原文件时，应使用处理前保留的审阅稿副本。

如果出现的是“错误”提示，而非完整的成功/失败统计，批次可能在处理中途停止。例如受保护文档无法解除保护时，后续文件可能尚未处理，此前已经成功保存的文件也不会整体回滚。请按输入文件清单核对处理到哪一步，再处理剩余文件。
