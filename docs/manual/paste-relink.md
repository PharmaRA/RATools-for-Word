# 粘贴并重连引用

**入口：RATools → 引用 → 粘贴并重连引用，宏列表，或快捷悬浮窗。**

适用于复制已有“正文引用 + 题注 + 图表”内容块。普通复制粘贴后，新的题注可能变成“表 2”，而新正文里的引用仍指向旧“表 1”。本工具将粘贴与引用重连合并处理。

## 一个典型例子

原文包括“结果见表 1”和“表 1 第一批样品结果”。复制这组内容，在新位置运行本功能后，新题注可能编号为“表 2”，粘贴块里的相关引用也会改指新题注。原文中的引用保持原来的目标。

序号由文档现有题注序列决定。重连后仍要检查引用是否确实跳到新题注，而不只是显示数字看起来正确。

## 操作步骤

1. 在同一文档中选中一整块需要复制的内容，**同时包含相关正文引用和完整题注**，按 `Ctrl+C`。
2. 将光标放到正文中的目标位置，通常使用空段落更容易检查结果。
3. 直接点击 **粘贴并重连引用**。不要先 `Ctrl+V`，再点击本工具，否则会多粘贴一份。
4. 检查新题注编号、新引用编号以及引用的跳转目标。
5. 按实际需要修改新题注的描述，再保存文档。

工具使用保留源格式的粘贴方式，寻找粘贴范围内的题注并重连引用；先更新题注编号等域，再更新引用域。它只更新粘贴范围内收集到的域，不替代整个文档的最终域检查。

## 哪些情况需要人工处理

| 情况 | 行为与处理方法 |
| --- | --- |
| 只复制了引用，没有复制对应题注 | 没有新的题注目标可供重连；根据需要重新插入交叉引用 |
| 引用指向章节标题或普通书签 | 这些目标不属于本工具的题注重连范围，保持原有引用关系 |
| 多个题注的标签和描述相同，无法唯一对应 | 相关引用保留原目标，并提示手动确认；必要时用 Word 交叉引用窗口逐项指定 |
| 从其他文档复制，原目标书签在当前文档中不存在 | 不能保证恢复源文档的引用关系，应逐项核对并必要时重新插入引用 |
| 在页眉、页脚、脚注等正文以外的区域使用 | 退化为普通的保留源格式粘贴，不执行题注重连 |
| 原引用已经失效，或者内容被粘为纯文本 | 工具无法可靠推断被删除的目标，需人工建立正确引用 |

## 撤销与失败处理

支持组合撤销的 Word 中，一次 `Ctrl+Z` 可以撤销本次粘贴及重连。旧版 Word 的撤销行为需以实际版本为准。

若提示“无法粘贴剪贴板内容”，重新复制目标内容后再试。若提示“内容已粘贴，但重连交叉引用时出错”，已粘贴内容会保留；先检查或撤销，不要连续重试导致重复插入。
