# 常见工作流程

本页把单项工具串成可操作的流程。各工具的处理范围与保存行为仍以对应功能页为准。

## 将一份资料统一为模板格式

1. 保存原稿副本，打开工作稿。
2. [加载中文或英文模板](templates.md)。
3. 从大到小整理章节层级，应用[标题1–9或无编号标题](styles.md)。
4. 给正文、列表、表格和图片分别应用对应样式，不要把全部内容一次设为正文。
5. 检查[页面设置](page-layout.md)、宽表、横向页和页眉页脚。
6. 插入或更新目录，检查目录层级和页码。
7. 保存后，在打印预览中检查分页、孤立标题和跨页表格。

检查点：标题应在导航窗格中形成合理层级；表标题样式与真正的题注编号要区分；有意保留的封面、附录页眉页脚不应被整篇统一覆盖。

## 新建图表并在正文中引用

1. 用 Word 插入图或表，填好内容。
2. 在正文的普通空段运行[生成题注与引用](caption-pairs.md)，选标签并填写描述。
3. 剪切整段题注到图表对应位置，保留完整域与书签。
4. 将引用放到“结果见……”等正文位置。
5. 应用表标题或图标题样式，更新相关域。
6. 检查显示编号和实际跳转目标，再保存。

如果是复制一组已经存在的图表、题注和正文，直接复制完整块，再使用[粘贴并重连引用](paste-relink.md)，逐项确认没有仍指向旧图表的引用。

## 集中审阅某位同事的修改

1. 打开[按审阅者筛选](review.md#reviewer-filter)。
2. 单击目标作者，再点“只看此人”。
3. 在 Word 中逐项阅读该作者的修订与批注，按你的审阅流程决定接受、拒绝或回复。
4. 完成后恢复“全部审阅者”，避免误把暂时隐藏的意见当成已经处理。
5. 如果格式变化已经确认、文字修改还待审阅，可以单独执行[接受格式修订](accept-format-revisions.md)。

检查点：筛选只改变显示；应分别检查真正剩余的修订和批注。

## 从审阅稿制作清洁稿并导出 PDF

1. 先把确认过的审阅稿复制为清洁稿工作副本，保留原审阅记录。
2. 使用[批量接受修订并删除批注](clean-documents.md)。多文件模式会写回所选文件，因此应选择刚准备的副本。
3. 用[高亮检测](highlights.md)寻找残留的可见高亮，逐处人工处理。
4. 检查隐藏文字、底纹、字体颜色等本工具未完整检查的内容。
5. 更新目录、题注和交叉引用，核对页码、跳转与颜色，保存 Word。
6. 运行 [Word 批量转 PDF](pdf-export.md)，已核对好域结果时选择“所见即所得”。
7. 打开 PDF 检查页数、版式、图表、目录与书签；若有失败项，查看报告并单独处理。

这些步骤帮助整理文档，最终内容及交付要求仍需按你的项目流程审核。

## 整理一组文件名

1. 准备待处理文件的清单和工作副本。
2. 选几种代表性的文件名，先在多文件模式试用[批量修改文件名](batch-rename.md)。
3. 确认小写、空格、符号替换规则符合需要后，再扩大到目标文件夹。
4. 核对重命名和创建副本的数量，并检查引用旧路径的索引或链接。

文件夹模式会进入子文件夹，且不局限于 Word。选定目录之前，应确认其内容都属于这次整理范围。
