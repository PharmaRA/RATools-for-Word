# 批量修改文件名

**入口：宏列表 → 批量修改文件名。** 用于把一组文件的名称统一成较简洁的格式。

## 处理范围

运行后先出现选择框：

- **是**：选择一个文件夹，递归处理其中及子文件夹中的文件，跳过 `~$` 开头的临时文件。
- **否**：打开多文件选择窗口，可选择任意类型文件。
- **取消**：退出。

该功能不仅处理 Word，也可能改名 PDF、Excel、图片等文件。它修改文件名，不修改文件夹名或文档内部引用这些文件的链接。

## 文件名如何变化

| 规则 | 例子 |
| --- | --- |
| 英文字母转小写，扩展名也转小写 | `Report.DOCX` → `report.docx` |
| 字母、数字之间的空白改成中划线 | `Study 01.docx` → `study-01.docx` |
| 汉字与其他内容之间的普通空格移除 | `稳定性 报告 A.docx` → `稳定性报告a.docx` |
| 主文件名保留规则范围内的汉字、a–z、0–9、中划线和下划线，其他字符替换为中划线 | `Report(01).pdf` → `report-01-.pdf` |
| 清理后主文件名为空 | 使用 `renamed-file` 作为主文件名 |
| 目标名称已被其他文件或目录占用 | 追加 `_1`、`_2` 等后缀，选择可用名称 |

该工具不会合并连续的中划线，也不保证去掉首尾中划线。英文以外的字母、特殊符号或不在规则范围内的汉字也可能被替换，先用代表性文件名试运行。

## 操作步骤

1. 明确要处理的文件范围；需要保留原名时先准备副本和原文件清单。
2. 运行宏并选择模式。
3. 选定文件或文件夹，确认后开始处理。当前工具没有改名前的逐项预览窗口。
4. 查看“直接重命名”和“创建副本”的数量。
5. 打开目标目录，核对新名称、同名后缀和文件总数。

## 被占用的文件与失败处理

直接重命名失败时，工具会尝试复制为新名称；复制成功后旧文件仍保留。如果两步均失败，文件不会计入成功数量，当前结果窗口也没有逐文件失败明细。因此应根据输入清单检查未变化的文件。

改名发生在文件系统层，不能用 Word 的 `Ctrl+Z` 批量恢复。外部超链接、其他系统记录的文件路径、人工维护的索引也不会同步改写。
