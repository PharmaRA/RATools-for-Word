# 修订、批注与按审阅者筛选

入口：**RATools → 审阅及修订**。

<a id="review-tools"></a>
## 新建批注和修订开关

| 功能 | 怎么使用 | 需要区分的行为 |
| --- | --- | --- |
| 新建批注 | 选中需要讨论的文字，点击新建批注，在 Word 的批注区域输入意见；按当前 Word 版本要求完成发布 | 给内容添加说明，不直接替换正文 |
| 修订 | 点击修订开关开启或关闭 Word 的修订记录 | 关闭后停止记录新的修改，但此前的修订仍然存在 |

修订或批注“看不见”不一定表示已清除。文档显示模式、审阅者筛选及 Word 的标记设置都会影响可见性。

<a id="reviewer-filter"></a>
## 按审阅者筛选

**入口：审阅及修订 → 按审阅者筛选，或宏列表中的同名功能。**

适合多人审阅时集中查看某个人或某组人的意见。面板根据当前文档的批注与修订作者建立列表。

1. 激活要审阅的文档，点击“按审阅者筛选”。
2. 勾选需要显示的作者，取消勾选需要暂时隐藏的作者。每次勾选立即生效。
3. 想集中查看一位作者时，先单击该作者，再点击 **只看此人**。
4. 需要恢复全部显示时，勾选 **全部审阅者**；该项也支持全部取消勾选。
5. 观察面板的“显示 X/Y 位审阅者”，完成后关闭面板。

面板不阻塞文档编辑。若文档内容或作者列表变化，重新点击功能入口可以强制刷新。没有批注或修订时会提示无需筛选。

## 这个工具不会改变什么

筛选调整的是当前文档窗口中作者标记的可见性，不会接受、拒绝或删除修订，也不清除批注。关闭面板不会自动恢复所有作者的显示；需要时使用“全部审阅者”。

作者名称按 Word 的实际记录识别，大小写不同的名称可能作为不同作者出现。列表中的统计帮助定位作者，不能代替审阅验收。若提示无法应用筛选，切换到 Word 的打印布局等可编辑视图，并确认 Word 当前允许显示修订标记。

## 三个容易混淆的工具

| 想完成的工作 | 应使用 |
| --- | --- |
| 临时只看某些人的意见 | 按审阅者筛选 |
| 接受字体、段落格式变化，保留文字增删修订 | [接受格式修订](accept-format-revisions.md) |
| 接受全部修订并去掉所有批注，制作清洁稿 | [批量接受修订并删除批注](clean-documents.md) |
