# 重命名当前文件与打开文件夹

<a id="rename-current"></a>
## 重命名当前文件

**入口：RATools → 其他 → 重命名当前文件，或宏列表中的同名功能。**

1. 先保存一次当前文档，确保它已有文件名和路径。
2. 点击工具，在输入框中填写新名称，**无需输入扩展名**。
3. 确认后，插件把当前文档另存为同文件夹下的新名称，沿用原扩展名，然后删除旧路径的文件。
4. 查看完成提示和 Word 标题栏，再用“打开所在文件夹”确认新文件。

例如输入 `研究报告_定稿`，原来是 `.docx` 的文档会保存为 `研究报告_定稿.docx`。输入空白或取消会退出；目标已有同名文件时会提示重新命名。

**这是会落盘的操作，也会保存当前尚未保存的编辑。** 当前实现删除旧文件时不经过回收站，不能依靠 Word 撤销恢复旧文件名。需要同时保留两个版本时，应使用 Word 的“另存为”。

如果报错发生在另存为之后，可能新文件已经存在而旧文件仍保留。先检查两个文件的内容与路径，再决定如何整理，不要立即反复运行。云端网址路径没有在此功能中做完整本地映射，建议先保存本地副本再操作。

<a id="open-folder"></a>
## 打开所在文件夹

**入口：RATools → 其他 → 打开所在文件夹。**

1. 激活目标文档。
2. 点击“打开所在文件夹”。
3. Windows 文件资源管理器打开该文档所在目录，你可以查看原文档、导出的 PDF 或备份。

尚未保存过的文档没有文件夹位置，会提示先保存。OneDrive/SharePoint 文档会尝试定位本机已同步的对应文件夹；无法匹配时会提示先完成本地同步。此操作只打开文件夹，不保存当前编辑，也不自动下载云端文档。
