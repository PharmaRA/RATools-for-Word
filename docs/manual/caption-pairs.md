# 生成题注与引用

**入口：RATools → 引用 → 生成题注与引用，或宏列表中的同名功能。**

适合新建一条图表题注，同时准备一处正文引用。工具在光标位置先生成交叉引用，再生成题注，两者已经关联。

## 操作前准备

- 打开可编辑的文档。
- 将光标放在**正文中、表格之外、现有域之外**，取消文字选区。页眉页脚、脚注等位置不支持此生成操作。
- 建议使用一个空段落，便于看清新生成的两段内容。

## 逐步操作

1. 点击“生成题注与引用”。
2. 在 **题注标签**中选择“表”“图”“Table”“Figure”等已有标签。
3. 没有需要的标签时，点击 **新建标签…**，输入如“附表”，确认。
4. 在 **题注文字**中输入“稳定性试验结果”。此项可以留空，之后再补。
5. 点击 **生成**，或使用窗口的默认确认键。

示例结果：

```text
表 1
表 1 稳定性试验结果
```

第一段只显示标签和编号，是可跳转的交叉引用；第二段含有 Word 原生题注编号及填写的描述。实际序号和编号形式沿用该标签在 Word 中的设置。

新生成的引用为标准蓝色，并加入保留域结果格式的设置。工具记住上次成功生成所用的标签；中英文标签不会互相翻译。

## 把引用和题注放到需要的位置

1. 在 Word 中显示段落标记，便于选中完整段落。
2. 选中整段题注，使用 `Ctrl+X` 剪切，再用 `Ctrl+V` 放到表格上方或图片旁的题注位置。
3. 按同样方式移动引用段落，再补充“见”“结果如”等正文文字。
4. 更新相关域；引用在题注前时，必要时再更新一次。
5. 检查引用的显示编号与跳转目标，保存文档。

移动时保留完整的域和书签。只复制屏幕上显示的文字、粘成纯文本，或者删掉原题注再手工输入同名内容，都可能失去关联。

## 取消、撤销和限制

- 点击“取消”会退出窗口；新标签只在窗口里暂存，未点击“生成”时不会注册。
- 在支持该撤销机制的 Word 中，一次 `Ctrl+Z` 可撤销整组生成。后续又做了其他编辑时，撤销顺序以 Word 为准。
- 标签与题注文字不能包含换行、制表符等控制字符。长题注可生成后在文档里继续编辑。
- 多组同名题注分别关联自己的引用。复制整组已有内容时，使用[粘贴并重连引用](paste-relink.md)，并检查重复描述带来的歧义。
- 该功能不自动插入图片或表格，也不替你选择图表在页面上的布局。

出现“请将光标放在正文中、表格外”的提示时，先关闭窗口，把光标移到普通正文空段再试。生成失败若提示自动撤销未成功，应立即检查插入位置，使用 Word 撤销或恢复练习副本。
