# 标准化科学术语下标

**入口：宏列表 → 标准化科学术语下标。** 按内置规则，把术语的数字或后缀改为 Word 字体下标，例如 `Cmax` 显示为 C<sub>max</sub>。

## 操作步骤

1. 只想处理部分内容时，选中完整术语所在的文字；没有选区、只有插入光标时，处理当前文档正文。
2. 在宏列表运行“标准化科学术语下标”。
3. 查看完成提示。当前提示使用英文 `Formatted N scientific term(s).`，表示匹配并处理的术语次数。
4. 检查下标范围是否符合你的文稿规范，确认后保存。

工具改变字体的下标属性，不把字符替换成 Unicode 下标字符。例如 `STD10` 的实际文字仍是 `STD10`，只是 `10` 显示为下标。

## 当前支持的规则

以下写法**区分大小写**。表中的“数字”表示一位或多位数字；主干保持普通基线，列出的后缀成为下标。

| 术语系列 | 支持的写法 | 下标部分 |
| --- | --- | --- |
| STD | `STD10` 等 `STD` 后接数字 | 数字 |
| C 最大/最小值 | `Cmax`、`Cmin`、`Cmax,ss`、`Cmin,ss` | `max`、`min` 或包含 `,ss` 的后缀 |
| T 最大/最小值 | `Tmax`、`Tmin` | `max`、`min`；不包含 `Tmax,ss` 这一扩展 |
| 药效/毒理终点 | `IC`、`EC`、`ED`、`ID`、`LD`、`LC`、`CC`、`TC`、`TD`、`GI` 后接数字，如 `IC50` | 数字 |
| MIC | `MIC50` 等 `MIC` 后接数字 | 数字 |
| E、I、B | `Emax`、`Emin`、`E0`，以及 I/B 的同类写法 | `max`、`min` 或 `0` |
| K | `Kd`、`Ki`、`Ka` | `d`、`i`、`a` |
| pK | `pKa`、`pKd`、`pKi` | 末尾的 `a`、`d`、`i` |
| k | `kon`、`koff`、`kel`、`ka`、`ke`、`k12` 等 k 后接数字 | `on`、`off`、`el`、`a`、`e` 或数字 |
| AUC 的 0 起点范围 | `AUC0-t`、`AUC0-inf`、`AUC0-last`、`AUC0-24h` 等整数小时、`AUC0-∞`、`AUC0-τ`、`AUC0-tau` | `0-` 开始的整个后缀 |
| AUC 其他后缀 | `AUCtau`、`AUClast` | `tau`、`last` |
| AUMC | `AUMClast`、`AUMCinf`、`AUMCtau` | `last`、`inf`、`tau` |
| MRT | `MRTlast`、`MRTinf`、`MRTtau` | `last`、`inf`、`tau` |
| 半衰期写法 | `t1/2` | `1/2` |
| C 其他后缀 | `C0`、`Ct`、`Css`、`Cavg`、`Cave`、`Ctrough` | C 后面的部分 |
| V | `Vd`、`Vz`、`Vss`、`Vc`、`Vp`、`V1`、`V2`、`V3` | V 后面的部分 |
| CL | `CLz`、`CLr`、`CLh`、`CLnr`、`CLint` | CL 后面的部分 |
| 小写 t | `tmax`、`tmin`、`tlag` | `max`、`min`、`lag` |

## 匹配边界与限制

术语通常需要作为独立标记出现。左右紧邻其他英文字母、数字或下划线时，不按完整术语匹配，避免把代码中的一部分误当术语。选区截断术语时也可能影响结果，应选中完整词。

工具只执行固定的排版规则，不判断科学意义或单位，不自动设置斜体，也不处理 Word 公式对象中的所有数学结构。未列出的写法应人工设置下标。

重复运行会重新应用匹配规则，提示数量可能包含已经具有下标格式的术语，不表示每个匹配项本来都存在错误。宏不自动保存或生成新文件，检查后自行保存。
