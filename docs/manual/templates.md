# 加载中文、英文和自定义模板

**入口：RATools → 模板 → 加载及其下拉菜单。**

样式模板决定标题、正文、表格文字等内容的格式。先保存当前文档，再导入模板；之后通过功能区把样式应用到相应段落。各样式的字体、字号、间距和编号以实际 `.dotx` 文件为准。

<a id="load-template"></a>
## 四种加载入口

| 按钮 | 操作和结果 |
| --- | --- |
| 加载（主按钮） | 查找插件同目录下的中文和英文模板。只找到一种时使用该模板；两种都存在时弹出选择窗口 |
| 加载中文模板 (CN) | 直接查找 `master-template-cn.dotx`；未找到时询问是否手动选文件 |
| 加载英文模板 (EN) | 直接查找 `master-template-en.dotx`；未找到时询问是否手动选文件 |
| 浏览其他模板… | 打开文件选择窗口，支持 `.dotx`、`.dotm`、`.dot`，取消选择则退出 |

主按钮发现两种模板时，弹窗中的 **是**选择中文，**否**选择英文，**取消**会转到手动选文件。若想完全退出，请再取消文件选择窗口。主按钮没有找到默认模板时，会先询问是否手动选择。

## 实际操作

1. 打开要排版的文档，保存一次。
2. 从下拉菜单明确选择中文或英文模板；自定义模板则选择“浏览其他模板”。
3. 等待导入完成提示。
4. 选中一段正文，点击 **正文-F**；再将一段标题应用 **标题1-F**，确认格式。
5. 保存当前文档。

导入的主要是名称以 `-F` 结尾的样式，以及匹配 TOC、图表目录等名称的目录样式。任意模板里的所有样式不会自动全部导入；没有找到符合条件的样式时会提示。

## 中英文模板如何配合按钮

按钮名称保持中文。应用样式时，插件先找同名中文样式；没有找到，再寻找对应的英文样式。例如“标题1-F”可对应 `Heading 1-F`。

如果同一文档同时保留了中文和英文样式，优先命中的可能仍是中文名称。因此，加载英文模板后不要假定所有段落都已经转为英文排版；检查实际样式，必要时在样式窗格中明确应用。中英文模板也不会自动翻译正文或把“表”改成“Table”。

## 已有文档和自定义模板

导入同名样式可能改变原来使用这些样式的段落外观。对已经精调过格式的正式稿，先保留副本，再检查标题编号、表格宽度和分页。

如果点击样式按钮时提示样式缺失，可以按提示加载模板；加载后，再点击一次原来的样式按钮完成应用。

修改模板只改变模板文件里的定义。已存在的文档需要重新导入并检查；详细步骤见[自定义模板](customization.md#custom-templates)。
