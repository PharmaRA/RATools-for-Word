# 题注、交叉引用与目录基础

入口：**RATools → 引用**。本页介绍功能区中的 Word 原生入口，以及“恢复题注标签”。首次接触这些功能时，先理解下面三个概念：

- **题注**：例如“表 1 稳定性试验结果”，编号由 Word 管理。
- **交叉引用**：正文中的“见表 1”，通过引用目标获取编号或页码，更新后能跟随目标变化。
- **域**：Word 用来生成编号、引用、目录等结果的动态内容。把它粘成纯文本会失去动态关联。

给一段文字应用“表标题-F”或“图标题-F”只改变样式，不会让手工输入的数字变成自动编号。

<a id="caption-reference"></a>
## 插入题注与交叉引用

| 功能 | 操作步骤 | 检查结果 |
| --- | --- | --- |
| 插入题注 | 选择对象或定位到题注位置，点击“插入题注”，选择表、图或自定义标签，填写文字并确认位置和编号选项 | 题注出现，序号是 Word 自动编号；再应用需要的表标题或图标题样式 |
| 插入交叉引用 | 把光标放到正文引用处，打开交叉引用窗口，选择引用类型和目标条目，再选择“只有标签和编号”等引用内容，插入 | 正文得到对应编号；需要跳转时勾选 Word 提供的超链接选项 |

例如，已有题注“表 3 含量测定结果”，在正文输入“结果见”，然后插入指向该题注的交叉引用。不要手工输入“表 3”来替代引用，否则后续增删表格时这处文字不会跟着更新。

如果希望一次建立一组新题注和引用，见[生成题注与引用](caption-pairs.md)；复制已有图表块时，见[粘贴并重连引用](paste-relink.md)。

<a id="restore-labels"></a>
## 恢复题注标签

**入口：引用 → 恢复题注标签。** 常见于接收他人文档后，正文已有“附表”等自动题注，但本机交叉引用窗口找不到对应类型。

1. 激活含有原题注的文档。
2. 点击“恢复题注标签”，等待完成提示。
3. 重新打开“插入交叉引用”，查看引用类型列表中是否出现需要的标签。

工具从当前文档正文域集合中的 `SEQ` 编号域读取标签，并把缺失项注册到本机 Word。它不创建已经丢失的题注文字或引用书签，也不能从手工输入的“表 1”识别出一个真正的自动题注。含空格等复杂自定义标签可能无法按预期识别，可在 Word 题注窗口手动新建准确标签。

<a id="contents"></a>
## 目录与图表目录

| 功能 | 操作步骤 | 适用情况 |
| --- | --- | --- |
| 插入目录 | 光标放在目录位置，打开目录对话框，选择显示层级及格式，确认 | 章节标题已经有正确大纲级别时，生成章节目录 |
| 更新目录 | 点击已有目录中的内容，再点击更新目录，按 Word 提示选择更新页码或整个目录 | 仅分页变化时更新页码；标题文字、顺序或层级变化时更新整个目录 |
| 插入图表目录 | 光标放在目标位置，打开图表目录窗口，选择需要汇总的题注标签，例如表或图 | 根据真正的题注生成表目录、图目录 |
| 更新图表目录 | 点击已有图表目录，运行更新，并按需要选择更新范围 | 增删图表或修改题注、页码后刷新 |

目录未收录某个标题时，检查其大纲级别和目录设置。图表目录未收录某条“表标题”时，检查它是不是 Word 题注，而非只有外观像题注的普通文字。

<a id="links-notes"></a>
## 超链接、书签、脚注与尾注

| 功能 | 操作步骤与结果 |
| --- | --- |
| 插入超链接 | 选中显示文字或定位光标，打开超链接窗口，输入目标文件、网址或文档位置并确认；按 Word 当前设置使用 Ctrl+单击等方式跳转 |
| 插入书签 | 选中需要标识的文字，或把光标放在定位点，打开书签窗口，输入符合 Word 规则的名称并添加；书签供跳转或交叉引用使用 |
| 插入脚注 | 将光标放在正文需要说明的位置，点击脚注按钮，在页面下方输入注释；需要统一格式时应用“脚注-F” |
| 插入尾注 | 将光标放在说明位置，点击尾注按钮，在 Word 指定的文档末尾或节末尾位置填写说明；位置和编号由 Word 设置决定 |

删除引用目标或覆盖带书签的文字可能使引用失效。遇到“错误！未找到引用源”，需要重新选择有效目标，单纯更新域不能恢复被删除的目标。

<a id="update-fields"></a>
## 更新域

1. 选中需要更新的题注、引用或其他域，点击 **引用 → 更新域**；也可以按 `F9`。
2. 需要更新正文时，可先在正文中 `Ctrl+A` 再更新。页眉、页脚、文本框等区域可能需要分别进入后更新。
3. 如果引用位于题注之前，先让题注编号更新，再更新引用；必要时重复一次。
4. 检查编号、页码、跳转目标和字体颜色，确认后保存。

这个按钮调用 Word 的更新域命令，作用范围取决于当前选区或所在域。锁定的域不会按普通更新方式刷新；“保护域代码格式”也不等于锁定域，区别见[域格式保护](field-format.md#protect-format)。
