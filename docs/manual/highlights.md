# 批量检测高亮内容

**入口：宏列表 → 批量检测高亮内容，或快捷悬浮窗对应按钮。**

适合在交付前寻找仍用“文本突出显示颜色”标记的待确认内容。此工具只检测和定位，不自动取消高亮。

## 检测当前文档

1. 激活目标文档，运行工具。
2. 模式输入 `1`。
3. 若发现高亮，选择是否跳到第一处命中。
4. 在该处确认内容，必要时通过 Word 的突出显示菜单选择“无颜色”。
5. 再次运行，继续检查剩余高亮。

当前文档模式不会列出全部命中，也不是循环跳转到下一处的导航器；只会定位本次检测到的第一处。

## 检测多个文档

1. 模式选择 `2` 多文件或 `3` 文件夹，指定目标。
2. 等待检测结束，新报告文档会列出文件路径、检测结果、命中内容和定位入口。
3. 对“包含高亮”的行，查看命中区域和文字摘要，**双击“跳转”**打开对应文档并定位第一处高亮。
4. 根据需要处理原文，完成后保存修改；报告也需要你另外保存。

报告中的命中内容只显示第一处的摘要，不是全文高亮清单。双击定位需要 RATools 处于加载状态，且源文件仍在原路径。生成报告后若内容改变，跳转时会重新查找，可能提示高亮已经不存在。

## 检测哪些内容

工具按 Word 文字区域查找，包括正文、页眉页脚、脚注尾注、批注和可遍历到的文本框等。只有带突出显示颜色的**可见内容字符**才算命中。

纯空白、段落或单元格结束标记、隐藏文字不会计为命中。字体标红、段落底纹、表格填充色也不是这里的“高亮”。因此，“无”不能解释为文档完全没有任何视觉标记或隐含内容。

## 怎样阅读失败状态

| 报告结果 | 含义与处理 |
| --- | --- |
| 包含高亮 | 至少有一处可见高亮；查看并处理后复查 |
| 无 | 本次范围内没有找到符合规则的高亮 |
| 无法打开文件 | 文件未完成检测，查看报告错误原因，处理权限、文件损坏或路径问题 |
| 检测失败 | 打开后检测过程发生异常，不能视为“没有高亮” |

批量检测本身不保存源文档。工具新开的只读文档在检测后关闭；原本打开的文档保持打开。
