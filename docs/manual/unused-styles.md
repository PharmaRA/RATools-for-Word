# 清理未使用的模板样式

**入口：宏列表 → 清理未使用的模板样式。**

多次加载或合并模板后，样式窗格可能积累很多没有使用的 RATools 样式。本工具清理当前文档中符合条件的样式定义。

## 操作步骤

1. 完成主要排版，检查标题、正文、页眉页脚和表格的样式。
2. 在宏列表中运行“清理未使用的模板样式”。
3. 查看删除的样式数量。
4. 打开样式窗格，确认仍在使用的样式和正文格式，检查后保存。

## 什么会被清理

候选对象必须是**名称以 `-F` 结尾的非 Word 内置样式**。工具检查文档各文字区域及样式依赖；被内容使用、被其他样式作为基础引用，或无法确定是否使用的样式会保留。

因此，看到一些没有直接应用到文字的样式仍留在列表中，并不一定是失败：它们可能作为其他样式的基础而存在。

## 影响与恢复

清理对象是当前文档内的样式定义，不会修改磁盘上的 `.dotx` 模板文件，也不会清理所有其他来源的自定义样式。

工具不自动保存。如果后来又需要已经清理的 RATools 样式，可以重新[加载模板](templates.md)；重新导入同名样式也可能影响现有排版，应检查后保存。
